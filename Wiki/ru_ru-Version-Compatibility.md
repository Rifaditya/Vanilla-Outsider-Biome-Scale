## 📊 Матрица совместимости версий Minecraft

**Vanilla Outsider: Biome Scale** поддерживается синхронно в современных версиях Minecraft в соответствии со строгой инженерной политикой **1 Jar 1 Version**.

| Версия Minecraft | Поколение | Номер сборки | Fabric Loader | Fabric API | Среда Java | Версия DasikLibrary | Статус поддержки |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **26.1.2** | Современный стандарт | `1.0.0+26.1` | `>=0.19.1` | `0.145.4+26.1.2` | Java 25 | `1.6.9+build.24` | 🟢 **Активная долгосрочная поддержка (LTS)** |
| **26.3-snapshot-6** | Передовой снапшот | `1.0.0+26.3` | `>=0.19.3` | `0.156.1+26.3` | Java 25 | `1.8.36` | 🟡 **Паритетный архив** |

## 🌐 Среда выполнения и безопасность сторон

| Среда | Поддерживается | Требования и поведение |
| :--- | :--- | :--- |
| **Выделенный сервер (Dedicated Server)** | ✅ **Полная поддержка** | **Требуется для генерации мира.** Все масштабирование координат чанков выполняется на стороне сервера во время создания мира и чанков. |
| **Одиночная игра (интегрированный сервер)** | ✅ **Полная поддержка** | Работает в потоке встроенного сервера; полное управление в реальном времени через `/gamerule` в чате. |
| **Ванильный клиент на сервере** | ✅ **Совместим с ванильным клиентом** | **Игроки с чистым ванильным клиентом могут заходить без установки мода!** Данные биомов передаются в стандартных палитрах пакетов чанков. |

## 🧩 Совместимость со сторонними модами на генерацию мира и биомы

Поскольку Vanilla Outsider: Biome Scale работает математически на уровне выборки координат (`MultiNoiseBiomeSource`) *до* поиска биома, он имеет встроенную совместимость с нулевыми накладными расходами со сторонними модами на генерацию мира:

```
[ Chunk Generator Pipeline ]
           │
           ▼
[ Vanilla Outsider: Biome Scale ]  <--- (Intercepts and dilates sampling coordinates: x' = x / S, z' = z / S)
           │
           ▼
[ Biome Source Registry ]
     ├── Vanilla Biomes (Plains, Desert, Jagged Peaks, etc.)
     ├── Terralith Biomes (Caldera, Mirage Desert, etc.)
     ├── Biomes O' Plenty (Cherry Blossom Grove, Outback, etc.)
     └── Datapack Custom Biomes
```

### Проверенные совместимые моды на генерацию
1. **Terralith**: Плавно расширяет пользовательские макро-биомы, сохраняя ванильную разводку пещер.
2. **Biomes O' Plenty**: Корректно масштабирует пользовательские поверхностные биомы без конфликтов ID.
3. **Regions Unexplored**: Совместим по всем настраиваемым параметрам регионов.
4. **Пользовательские датапаки генерации**: Любой датапак, использующий ванильные источники `minecraft:multi_noise`, масштабируется автоматически.

## 🛠️ Требования к среде выполнения Java (JRE)

Артефакты сборки Minecraft 26.1 и 26.3 требуют **Java 25 (LTS)**. Попытка запуска на Java 21 или более ранней версии вызовет предупреждение о несовместимости байткода загрузчика классов JVM:

```
UnsupportedClassVersionError: net/vanillaoutsider/biomescale/BiomeScaleFabric has been compiled 
by a more recent version of the Java Runtime (class file version 69.0)
```

```bash
# Verify your installed Java version
java -version
# Expected: openjdk version "25" (or higher)
```
