## 🌍 バイオームスケール ドキュメントセンターへようこそ

**Vanilla Outsider: Biome Scale** は、最新のMinecraft Fabric環境向けに設計された、軽量で数学的に洗練されたワールド生成拡張Modです。ワールド生成時のマルチノイズ（Multi-Noise）気候座標サンプリングをインターセプトすることにより、バニラのノイズ式を変更したり人工バイオームを追加したりすることなく、バイオームの境界を有機的に拡大します。

サバンナ、メサ（悪地）、暗い森、雪原がわずか数百ブロックの間隔で激しく混在する、悪名高い「フルーツサラダ問題」を解決し、ノイズマップを拡張してリアルで広大な大陸スケールのバイオームを生成します。

```

|                        VANILLA OUTSIDER: BIOME SCALE                              |
|                                                                                   |
|     バニラ生成 (バイオームの過密・細分化)             スケール拡張後 (広大な大陸バイオーム)   |
|   +----+----+----+----+----+----+----+----+    +----------------------------------+  |
|   | 砂 | 平 | ジ | 悪 | 雪 | 森 | サ | 湿 |    |                                  |  |
|   +----+----+----+----+----+----+----+----+    |                                  |  |
|   | 平 | ジ | 砂 | タイ| 森 | サ | 砂 | 平 |    |               砂漠               |  |
|   +----+----+----+----+----+----+----+----+    |            (x2.0 - x4.0)         |  |
|   | 悪 | 砂 | 雪 | 湿 | 平 | 森 | ジ | 悪 |    |                                  |  |

```

## ⚡ 主要な技術仕様

1. **純粋な座標拡大（実行速度 $\mathcal{O}(1)$）**:
   - `MultiNoiseBiomeSource.getNoiseBiome` 内で座標 $x' = \lfloor x / S \rfloor$ および $z' = \lfloor z / S \rfloor$ を直接変換。
   - バイオームサンプリング中のガベージコレクション（GC）ヒープ割り当ては**0バイト**。
2. **動的GameRuleシステム**:
   - **DasikLibrary** の `DynamicGameRuleManager` を利用し、`biome_scale:biome_scale` 名前空間に登録。
   - サーバーを再起動することなく、ゲーム内コマンド `/gamerule biome_scale:scale_modifier <値>` で倍率を即座に変更可能。
3. **Mod追加バイオームとの完全なネイティブ互換性**:
   - バイオームレジストリの手前で座標変換が行われるため、TerralithやBiomes O' Plentyなどの外部ワールド生成Modも自動的に拡大されます。
4. **ボロノイ（Voronoi）境界の連続性維持**:
   - 気候パラメータ（気温・湿度・大陸性・侵食度・深度・奇異性）の連続場を拡大するため、チャンク境界でのグラデーションが自然に保たれます。
