## 🌲 Overview: Biome Scale for Minecraft 26.1

Welcome to the dedicated documentation suite for **Vanilla Outsider: Biome Scale** targeting **Minecraft 26.1 (26.1.2)**. 

In Minecraft 26.1, world generation relies heavily on the `MultiNoiseBiomeSource` climate sampler, evaluating points in a 6-dimensional parameter space (temperature, humidity, continentalness, erosion, depth, weirdness). Biome Scale dynamically intercepts these coordinates, dilating the horizontal noise sampling space by a configurable multiplier.

## 🚀 Quick Start Guide for Server Admins

1. **Install Dependencies**:
   - Ensure your server has **Fabric Loader `>=0.19.1`** and **Fabric API `0.145.4+26.1.2`**.
   - Install **DasikLibrary `>=1.6.9`**.
2. **Drop JAR**:
   - Place `vanilla-outsider-biome-scale-1.0.0+26.1.jar` into your server's `mods/` folder.
3. **Configure Biome Sizes**:
   - Standard scale modifier is **`200`** (which represents a $2.0\times$ expansion):
     ```text
     /gamerule biome_scale:scale_modifier 200
     ```
   - For massive continental worlds ($4.0\times$ expansion):
     ```text
     /gamerule biome_scale:scale_modifier 400
     ```
   - For rapid micro-biomes ($0.5\times$ size):
     ```text
     /gamerule biome_scale:scale_modifier 50
     ```
