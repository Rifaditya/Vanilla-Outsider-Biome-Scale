## 🌍 바이옴 스케일 문서 센터에 오신 것을 환영합니다

**Vanilla Outsider: Biome Scale**은 최신 Minecraft Fabric 환경을 위해 설계된 가볍고 수학적으로 정교한 월드 생성 개선 모드입니다. 월드 생성 중 멀티 노이즈(Multi-Noise) 기후 좌표 샘플러를 가로채 바닐라 노이즈 수식을 변경하거나 인공 바이옴을 추가하지 않고도 유기적으로 바이옴 경계를 확장합니다.

사바나, 악지(메사), 어두운 숲, 눈 덮인 평원이 불과 수백 블록 간격으로 어지럽게 뒤섞이는 악명 높은 "과일 샐러드" 바이옴 혼잡 문제를 해결하여 노이즈 맵을 확장하고 사실적이고 광활한 대륙 단위 바이옴을 형성합니다.

```
+-----------------------------------------------------------------------------------+
|                        VANILLA OUTSIDER: BIOME SCALE                              |
|                                                                                   |
|     바닐라 생성 (바이옴 과밀 및 잦은 파편화)          스케일 확장 후 (광활한 대륙 바이옴)     |
|   +----+----+----+----+----+----+----+----+    +----------------------------------+  |
|   | 사 | 평 | 정 | 악 | 눈 | 숲 | 사 | 늪 |    |                                  |  |
|   +----+----+----+----+----+----+----+----+    |                                  |  |
|   | 평 | 정 | 사 | 타 | 숲 | 사 | 사 | 평 |    |               사막               |  |
|   +----+----+----+----+----+----+----+----+    |            (x2.0 - x4.0)         |  |
|   | 악 | 사 | 눈 | 늪 | 평 | 숲 | 정 | 악 |    |                                  |  |
|   +----+----+----+----+----+----+----+----+    +----------------------------------+  |
+-----------------------------------------------------------------------------------+
```

## ⚡ 핵심 기술 사양

1. **순수 좌표 확장 ($\mathcal{O}(1)$ 실행 시간)**:
   - `MultiNoiseBiomeSource.getNoiseBiome` 내부에서 좌표 $x' = \lfloor x / S \rfloor$ 및 $z' = \lfloor z / S \rfloor$를 직접 변환.
   - 바이옴 샘플링 중 가비지 컬렉터(GC) 힙 메모리 **0바이트 할당**.
2. **범용 동적 게임 규칙 (GameRules)**:
   - **DasikLibrary**의 `DynamicGameRuleManager`를 기반으로 `biome_scale:biome_scale` 네임스페이스에 등록.
   - 서버 재시작 없이 인게임 명령어 `/gamerule biome_scale:scale_modifier <값>`으로 실시간 배율 조정.
3. **외부 모드 바이옴 완벽 호환**:
   - 개별 바이옴 레지스트리 상단에서 좌표 변환이 이루어지므로 Terralith, Biomes O' Plenty 등 모든 타사 월드 생성 모드가 자동으로 확장됩니다.
4. **보로노이(Voronoi) 셀 경계 보존**:
   - 기후 매개변수의 연속 필드를 확장하여 청크 경계에서 부드럽고 유기적인 전환을 보장합니다.
