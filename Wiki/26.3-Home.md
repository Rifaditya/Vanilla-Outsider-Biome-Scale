## 🚀 Quick Start Guide for Server Admins (Snapshot Era)

1. **Install Dependencies**:
   - Ensure your server has **Fabric Loader `>=0.19.3`** and **Fabric API `0.156.1+26.3`**.
   - Install **DasikLibrary `>=1.8.36`**.
2. **Drop JAR**:
   - Place `vanilla-outsider-biome-scale-1.0.0+26.3.jar` into your server's `mods/` folder.
3. **Configure Biome Sizes**:
   - Standard scale modifier is **`200`** (which represents a $2.0\times$ expansion):
     ```text
     /gamerule biome_scale:scale_modifier 200
     ```
   - For massive continental worlds ($4.0\times$ expansion):
     ```text
     /gamerule biome_scale:scale_modifier 400
     ```
   - For rapid micro-biomes ($0.5\times$ size):
     ```text
     /gamerule biome_scale:scale_modifier 50
     ```
