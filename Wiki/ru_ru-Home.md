## 🌍 Добро пожаловать в центр документации Biome Scale

**Vanilla Outsider: Biome Scale** — это легковесный и математически выверенный мод для генерации мира в среде Minecraft Fabric. Перехватывая низкоуровневые сэмплеры координат мульти-шума (Multi-Noise), он органично расширяет границы биомов, не изменяя ванильные формулы шума и не создавая искусственных биомов.

Мод решает проблему «фруктового салата» — хаотичного скопления крошечных биомов, когда саванна, пустоши, тёмный лес и снежные равнины сменяются каждые несколько сотен блоков. Мод растягивает карты шума, создавая обширные, реалистичные континентальные биомы.

```
+-----------------------------------------------------------------------------------+
|                        VANILLA OUTSIDER: BIOME SCALE                              |
|                                                                                   |
|     Ванильная генерация (частая смена биомов)       Масштабирование (огромные континенты) |
|   +----+----+----+----+----+----+----+----+    +----------------------------------+  |
|   | ПУС| РАВ| ДЖУ| БЕД| СНЕ| ЛЕС| САВ| БОЛ|    |                                  |  |
|   +----+----+----+----+----+----+----+----+    |                                  |  |
|   | РАВ| ДЖУ| ПУС| ТАЙ| ЛЕС| САВ| ПУС| РАВ|    |             ПУСТЫНЯ              |  |
|   +----+----+----+----+----+----+----+----+    |            (x2.0 - x4.0)         |  |
|   | БЕД| ПУС| СНЕ| БОЛ| РАВ| ЛЕС| ДЖУ| БЕД|    |                                  |  |
|   +----+----+----+----+----+----+----+----+    +----------------------------------+  |
+-----------------------------------------------------------------------------------+
```

## ⚡ Ключевые технические особенности

1. **Дилатация координат с производительностью $\mathcal{O}(1)$**:
   - Преобразование координат $x' = \lfloor x / S \rfloor$ и $z' = \lfloor z / S \rfloor$ прямо в `MultiNoiseBiomeSource.getNoiseBiome`.
   - **0 байт аллокаций** в куче сборщика мусора (GC) при выборке биомов.
2. **Динамические игровые правила (GameRules)**:
   - Интеграция с **DasikLibrary** (`DynamicGameRuleManager`) в пространстве имён `biome_scale:biome_scale`.
   - Мгновенная настройка множителя командой `/gamerule biome_scale:scale_modifier <значение>` без перезагрузки сервера.
3. **Естественная совместимость с модами на биомы**:
   - Поскольку масштабирование происходит на уровне координат до реестра биомов, сторонние моды (Terralith, Biomes O' Plenty) масштабируются автоматически.
4. **Сохранение границ ячеек Вороного**:
   - Масштабирует непрерывное поле мульти-шума (температура, влажность, континентальность, эрозия, глубина, странность), сохраняя гладкие переходы на границах чанков.
