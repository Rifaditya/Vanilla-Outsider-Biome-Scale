# ⚒️ Vanilla Outsider: Biome Scale

**Summary:** Organically stretches terrain to create vast, cohesive continents without clashes, solving the "fruit salad" biome problem with one click.

**Active Version Policy:** I build **1 JAR for 1 Version**. I only update and maintain the latest active Minecraft version (e.g. when 26.3 is released, 26.2 is retired). No backports or legacy version maintenance. Please do not ask.

> **"Respect the Player's Time, Not the Game's Rules."**

**Vanilla Outsider: Biome Scale** is a Biome Scale Tweaker. Part of the **Instant Gratification Collection** — mods that respect the player's time.

---

## ✨ Features

### 🛡️ Universal Noise Rescaling
By adjusting the MultiNoiseBiomeSource parameters under the hood, all vanilla and modded biomes naturally stretch to create massive, realistic continents. Compatible automatically with datapacks and terrain generators like Terralith.

### ⚙️ Real-Time Configuration
Scale is dynamic! Use the `Global Biome Scale Modifier` game rule to adjust the scale instantly. By default, biomes are 2x their vanilla size (200%). Set it to 50% for micro-biomes!

## 📋 Quick Start
  
  1. Install **[Fabric API](https://modrinth.com/mod/fabric-api)**.
  2. Download `vanilla-outsider-biome-scale-1.0.0.jar` and place it in your `mods` folder.
  3. Launch the game.
