# Player Guide

**Vanilla Outsider: Biome Scale** Biome Scale Tweaker.

## Features
Organically stretches terrain to create vast, cohesive continents without clashes, solving the "fruit salad" biome problem with one click.

## Configuration
Use the GameRule `biome_scale:scale_modifier` (default: 200).
A value of 200 represents 2.0x standard biome size.
