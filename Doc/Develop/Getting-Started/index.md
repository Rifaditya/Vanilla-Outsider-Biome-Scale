# Getting Started

## Requirements

| Dependency | Version |
| :--- | :--- |
| Minecraft | 26.+ |
| Fabric Loader | ≥ 0.19.1 |
| Fabric API | 0.145.4+26.1.2 |
| Java | 25 |

## Building from Source

```bash
git clone <repo-url>
cd vanilla-outsider-biome-scale
./gradlew build
```

The JAR will be in `build/libs/vanilla-outsider-biome-scale-<version>.jar`.
